Useful work, not another chatbot

Coding agents need exact, machine-readable results they can act on. PatchSignal does the deterministic lookup and formatting step, without inventing fixes or relying on model-generated security claims.

⌁

Exact-version checks

Checks locked package versions against OSV.dev. It ignores version ranges instead of pretending they are installed versions.

✓

Actionable JSON

Returns advisory IDs, aliases, severity where the source provides it, known fixed versions, dates, and references.

↗

Agent discovery

Includes an OpenAPI schema, an llms.txt guide, and x402 Bazaar metadata on the paid API route.

One API call

Start with an npm package-lock.json or pinned Python requirements file. You can also send normalized package records from any supported ecosystem.

$0.005 USDC per audit request · configurable

One request can include up to 250 exact dependencies by default. The limit is configurable. The service caches repeat lookups briefly to reduce load.

The price is a proposed starting point, not a promise of earnings or traffic. Paid agents must support x402 and have a funded payment setup to use the paid route.
curl -X POST "$PATCHSIGNAL_URL/v1/audit" \\ -H "Content-Type: application/json" \\ -d '{ "format": "dependencies", "dependencies": [{ "name": "lodash", "version": "4.17.19", "ecosystem": "npm" }] }' # For a paid deployment, use an x402-compatible # client so it can respond to HTTP 402 automatically.

Transparent by design

No LLM provider key is required for the audit itself. The report is only as complete and current as the upstream advisory database; it is a useful signal, not a guarantee that a package or application is secure.
